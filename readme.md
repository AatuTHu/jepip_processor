# Custom Processor named JEPIP or J32P

## Currently
- 19.10 Early stages. Currently 8bit circuit with 10bit instructions spliced 2 bits for register selection and 8 for value.
- 20.10 32 bit wide instructions, 16 registers, 4 bits for opcode, 4 bits for rd, 4 bits for rs and 20 for imm_data.

## Future
- 32 processor with custom isa & assembler. 
- Able to run programs
- Able to run TaaviOS
